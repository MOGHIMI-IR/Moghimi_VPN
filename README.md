## درباره برنامه

**Moghimi VPN** یک اپلیکیشن بومی اندروید برای اتصال ساده و هوشمند است. برنامه سرورهای فعال منتشرشده در سایت مقیمی را دریافت می‌کند، کیفیت اتصال آن‌ها را بررسی می‌کند و می‌تواند بهترین گزینه‌ی در دسترس را به‌صورت خودکار انتخاب کند.

کاربر به‌جای درگیرشدن با جزئیات فنی، فقط سرور هوشمند را انتخاب می‌کند و روی دکمه‌ی اتصال می‌زند.

## تجربه‌ای که می‌سازیم

- صفحه‌ی اصلی اختصاصی با طراحی تیره، پرجزئیات، موشن‌های نرم و جلوه‌های نوری.
- اتصال و قطع اتصال با یک دکمه‌ی مرکزی.
- حالت اتصال هوشمند برای بررسی گزینه‌های فعال و انتخاب مسیر مناسب.
- نمایش وضعیت اتصال، تأخیر، IP خروجی و کشور تقریبی در صورت شناسایی.
- تلاش مجدد روی گزینه‌ی بعدی در صورت شکست اتصال.
- همگام‌سازی خودکار فهرست سرورهای منتشرشده در سایت.
- بدون نمایش جزئیات فنی موتور اتصال در رابط کاربری عادی.

## وضعیت پروژه

این مخزن محل توسعه‌ی نسخه‌ی جدید Moghimi VPN است. تا زمانی که بیلد، تست‌های خودکار و آزمایش روی دستگاه واقعی تکمیل نشده‌اند، خروجی‌ها آزمایشی محسوب می‌شوند.

## ساختار

- `android/upstream`: سورس پایه‌ی متن‌باز و پین‌شده‌ی موتور اتصال اندروید که در زمان Build دریافت می‌شود.
- `android/src`: کد همگام‌سازی، نمایش اطلاعات IP/کشور و تجربه‌ی اختصاصی مقیمی.
- `.github/workflows`: ساخت خودکار APK، بررسی‌ها و انتشار نسخه‌ها.

## امنیت و شفافیت

- تأیید مجوز VPN فقط از طریق پنجره‌ی سیستمی اندروید انجام می‌شود.
- کلید عمومی Supabase برای خواندن داده‌های مجاز استفاده می‌شود؛ کلید مدیریتی یا service-role داخل برنامه قرار نمی‌گیرد.
- برای نمایش کشور، برنامه پس از اتصال، IP خروجی را از سرویس تشخیص موقعیت IP استعلام می‌کند؛ کشور تقریبی است و به GPS یا موقعیت دقیق گوشی متکی نیست.
- سرویس تشخیص IP شخص ثالث ممکن است IP خروجی را دریافت کند؛ این موضوع در راهنمای حریم خصوصی توضیح داده می‌شود.
- هیچ آنتی‌ویروسی را نمی‌توان از پیش تضمین کرد که هرگز هشدار ندهد؛ منشأ انتشار، امضای ثابت، checksum و مجوزهای حداقلی بررسی می‌شوند.

## مجوزها

موتور اتصال بر پایه‌ی پروژه‌های متن‌باز upstream است. مجوزها و اطلاعیه‌های وابستگی‌ها در `android/THIRD_PARTY_NOTICES.md` ثبت خواهند شد.
